## Projects

### Locus AI

> LLMs reason, RAG retrieves, agents execute. **Locus AI remembers.**

Decisions get made in Slack threads, tickets and docs, then lost. Locus AI captures them as structured records and serves them to people and agents through MCP, so an agent checks what the team already decided before it acts. 2nd place, AI PM Accelerator Cohort 9.

```mermaid
flowchart LR
    A[Slack · Gmail · Jira<br/>Notion · Confluence · 20+ connectors] --> B[Haiku triage]
    B --> C[Sonnet extraction<br/>decision records]
    C --> D[(Postgres + pgvector<br/>RBAC-scoped memory)]
    D --> E[Hybrid retrieval<br/>vector + BM25 + recency]
    E --> F{{MCP server}}
    F --> G[AI agents]
    F --> H[People: Decision Radar,<br/>Context Search]
    G -- log_decision<br/>as proposed --> I[Human approval]
    I --> D
```
